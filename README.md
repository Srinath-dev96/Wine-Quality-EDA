# Wine Quality Exploratory Data Analysis (EDA)

## Project Overview
This project explores the Red Wine Quality dataset using Python to understand the relationship between wine chemical properties and quality ratings.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Dataset overview
- Statistical analysis
- Missing value and duplicate checking
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Data visualization

## Dataset
Wine Quality – Red Wine dataset.

Source: https://archive.ics.uci.edu/dataset/186/wine+quality

## Project File
'wine_quality.ipynb'

## Objective
To explore the dataset, identify patterns and understand the factors associated with wine quality.
